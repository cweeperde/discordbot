## What Botanaki can do

| 🛡️ Moderation & safety | 🌱 Community | 📊 Progress & stats |
| --- | --- | --- |
| Local chat and invite filtering | Welcome messages and reaction roles | XP, levels, rank cards, and leaderboards |
| Reports and private moderator notes | Starboard and counting | Member and server information |
| Tickets and anonymous ticket relay | Birthdays and reminders | Live weather and utility commands |
| Optional audit-log archiving | Custom server setup flow | Image-based cards with adaptive accents |

## Designed for real servers

- **Configurable:** Features can be enabled and tailored per server.
- **Privacy-aware:** Data use and retention are documented clearly, including a grace period after the Bot leaves a server.
- **Abuse-resistant:** Persistent cooldowns, global user restrictions, server self-bans, and manual appeals protect the service.
- **Discord-native:** Slash commands, buttons, dropdowns, modals, private threads, and generated images keep interactions clean and familiar.

## Get started

1. Click **Add Botanaki to Discord** above.
2. Choose a server where you have permission to add apps.
3. Run `/setup-assistent` for guided server configuration or `/help` to browse commands.
4. Review the [Privacy Policy](privacy_policy.md) and [Terms of Service](terms_of_service.md) before enabling features for your community.
